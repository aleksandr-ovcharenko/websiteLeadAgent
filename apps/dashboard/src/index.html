Leads Dashboard

Что означают метрики (коротко)
подсказка: поиск ищет по компании/домену/сайту/телефону/адресу/заметке
leadScore (old) — старый общий скор (M4), в основном по Lighthouse + базовые сигналы бизнеса.
leadScoreV2 — новый общий скор (M5): комбинация tech + visual + biz и потенциала редизайна.
web — websiteQualityScore (детерминированный скор по Lighthouse и crawl-сигналам сайта).
tech — technicalQualityScore (сейчас берётся из web как прокси).
biz — businessConfidenceScore (сейчас берётся из businessScore как прокси уверенности в ценности лида).
visual — визуальный скор из AI (агрегация субоценок: modernity/visualQuality/mobileUX/иерархия/CTA/структура/доверие/бренд).
AI status — статус AI-анализа скриншотов (PENDING/SUCCESS/FAILED). В правой панели: summary + списки problems/strengths.
rp — redesignPotential (1..10). Чем выше, тем сильнее “потенциал редизайна” (с точки зрения AI).
Manual — ручная квалификация: UNREVIEWED/GOOD/BAD/UNSURE. Можно ставить статус и заметку без перезагрузки.
Lighthouse — краткие метрики perf/seo/acc/bp из последнего отчёта. Используются для web/leadScore.
Как интерпретировать ("больше лучше" / "меньше лучше")
leadScoreV2 — больше лучше: выше приоритет лида для контакта.
visual — больше лучше: сайт визуально сильнее. При этом высокий rp может означать, что редизайн всё равно продаётся хорошо (сайт “просит” апгрейд).
rp — больше = выше потенциал редизайна. Обычно полезно, когда biz нормальный, но visual/web слабые.
biz — больше лучше: выше шанс, что компания активная/платёжеспособная/контактируемая.
web / tech — больше лучше: выше техническое качество/скорость/базовые практики.
Практичные пороги (ориентиры, не жёсткие правила)
leadScoreV2:
70-100 = топ-кандидаты
50-69 = хорошие кандидаты
30-49 = средние (только если ниша важная)
0-29 = низкий приоритет
AI:
status=FAILED = нет AI данных (не обязательно плохой лид)
problems/strengths = конкретные поводы для первого сообщения/звонка
Контакты: что подходит для кандидата
Телефон — чаще всего самый быстрый контакт. Хорошо, если:
номер не пустой, выглядит как реальный (не 0000...)
соответствует региону/стране (обычно +375 / местные форматы)
Сайт — must-have для редизайна. Хорошо, если:
есть websiteDomain (не соцсеть/агрегатор)
сайт открывается, есть страницы услуг/контактов
есть явные CTA (форма/кнопки/контакты)
Адрес — повышает доверие и помогает в сегментации (район/город).
Manual note — можно использовать как "память": что уже проверено и почему GOOD/BAD.
