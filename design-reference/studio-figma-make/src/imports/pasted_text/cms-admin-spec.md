Design a complete professional CMS Admin interface for a multi-tenant website management platform.

Product name:

WebsiteLeadAgent CMS

This CMS manages small and medium business websites generated by our platform.

IMPORTANT:
This is NOT a marketing website.

Do not reuse the visual style of the public construction website.

The CMS must feel:

- professional
- strict
- calm
- efficient
- trustworthy
- modern B2B software
- information-dense but not cluttered
- easy for a non-technical business owner

Think:

modern enterprise admin
+
high-quality SaaS dashboard
+
content management system

NOT:

consumer mobile app
marketing landing page
glassmorphism
creative portfolio
futuristic UI

==================================================
DESIGN LANGUAGE
==================================================

Use a restrained professional palette.

Main UI:

- light neutral background
- white surfaces
- graphite / dark text
- subtle borders
- muted secondary text

Accent:
restrained green

Green may reference the current Garant Kachestva brand,
but the admin must NOT feel branded specifically for one customer.

Avoid:

- huge rounded cards
- excessive shadows
- glass effects
- strong gradients
- colorful dashboard widgets
- decorative illustrations
- oversized typography
- excessive whitespace
- mobile-app-like cards everywhere

Use:

- clean tables
- clear hierarchy
- compact controls
- subtle radius
- strong spacing system
- clear states
- accessible contrast

a project

Can the user easily find:

phone numbers
navigation
site branding
SEO
media

Does it avoid looking like a website landing page?

Does it avoid excessive visual decoration?
